核心功能

不止是命令别名，
而是一个懂你的助手

从架构识别到权限修复，从输入校验到状态反馈——每一个容易踩坑的细节，都替你想好了。

智能架构检测

自动识别当前系统架构 x86_64、aarch64、arm，并精准匹配对应的 cloudflared 二进制文件名，告别"下载错版本"的烦恼。

二进制文件自动管理

  • 自动下载：缺少 cloudflared 时，询问并从 GitHub 官方仓库拉取最新版本。
  • 自动授权：自动执行 chmod +x，彻底解决"权限不足"的经典报错。

交互模式

直接运行脚本，通过清晰的问答引导输入主机名与端口，新手和不常用的连接都不再需要翻笔记。

参数模式

在命令后直接附上主机名与端口，一行搞定；也方便熟练用户集成到别的脚本或快捷方式中。

强大的输入验证

  • 端口必须是 1–65535 内的有效数字。
  • 端口低于 1024 时贴心提醒可能需要 sudo。

清晰的帮助与错误提示

标准的 -h / --help 随时查阅；执行的每一步都给出明确的状态反馈或错误信息，让你始终知道发生了什么。

如何使用

三步上手

下载、授权、运行。之后每次连接，只需要回答两个问题——或者一行参数。

1

获取脚本

下载 cf-helper.sh，建议与 cloudflared 放在同一目录。

2

授予执行权限

进入脚本所在目录后运行：

chmod +x cf-helper.sh
3

运行脚本

选择右侧任一方式启动隧道连接。

推荐方式。直接运行脚本，它会引导你完成每一步。

./cf-helper.sh
请输入隧道地址 (hostname): your-tunnel.example.com
请输入本地监听端口 [21128]:
端口留空将使用默认值 21128，随后用任意客户端连接 localhost:21128 即可。
若端口低于 1024，脚本会提醒你可能需要 sudo 权限。

快速方式。直接在命令后提供所有必需参数，适合熟练用户或脚本集成。

# 用法: ./cf-helper.sh [HOSTNAME] [PORT]
# 示例:
./cf-helper.sh your-tunnel.example.com 21128

小技巧：为常用连接创建别名，一个单词即可连上。

# 写入 ~/.bashrc 或 ~/.zshrc
alias nas='~/cf-helper/cf-helper.sh nas.example.com 3389'

查看所有可用的命令和说明。

./cf-helper.sh --help
# 或简写
./cf-helper.sh -h
脚本在每一步都会输出明确的状态或错误信息，遇到问题时先看看终端输出。
若目录中没有 cloudflared，脚本会询问是否自动从官方仓库下载。
